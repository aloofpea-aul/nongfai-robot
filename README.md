# น้องไฟ – หุ่นยนต์บริการลูกค้า กฟส.อ่าวลึก

ขั้นที่ 1: ซอฟต์แวร์บนจอ (เว็บแอปบน GitHub Pages)

- มาสคอต 3D (three.js) กะพริบตา ขยับปากตอนพูด มองตามนิ้ว
- ฟังเสียงภาษาไทย (Web Speech API ใน Chrome) และพูดตอบภาษาไทย
- คุยผ่าน Gemini API แบบสตรีม พูดทีละประโยคเพื่อให้ตอบไว
- หน้าทักทาย / หน้าตอบคำถามพร้อมการ์ดข้อมูล / ตั้งค่า

## ใช้งาน
1. เปิดหน้าเว็บด้วย Google Chrome บนแท็บเล็ตหรือมือถือ Android
2. แตะไอคอนตั้งค่ามุมขวาบน ใส่ Gemini API key แล้วกดบันทึก (key เก็บในเครื่องนั้นเท่านั้น)
3. แตะปุ่มไมค์แล้วพูด

ถ้าไม่มีเสียงภาษาไทย: ติดตั้ง/อัปเดต "Speech Recognition & Synthesis by Google" และเพิ่มภาษาไทย
